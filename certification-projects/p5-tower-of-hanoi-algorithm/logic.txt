Note: This is a stream-of-consciousness note as I work out the pattern in solving the puzzle. It's not 100% clear,
not perfect, and references some strategies that aren't described or implemented. Included to show problem solving
technique, not to indicate the solution to the problem.

    Even numbers start at column 1, Odd numbers start at column 2

    2,1             --start at 1
    2       1                       a -> b      move stack 2
            1       2               a -> c
                    2,1             b -> c
    -----------------------------
    3,2,1           --start at 2
    3,2             1               a -> b      move stack 2
    3       2       1               a -> c
    3       2,1                     b -> c

            2,1     3               a -> b      move 1

    1       2       3               c -> a      move stack 2
    1               3,2             c -> b
                    3,2,1           a -> b
    -----------------------------
    4,3,2,1         --start at 1
    4,3,2           1               a -> b      move stack 2
    4,3     2       1               a -> c
    4,3     2,1                     b -> c

    4       2,1     3               a -> b      move 1

    4,1     2       3               c -> a      move stack 2
    4,1             3,2             c -> b
    4               3,2,1           a -> b

            4       3,2,1           a -> c      move 1

            4,1     3,2             b -> c      move stack 2
    2       4,1     3               b -> a
    2,1     4       3               c -> a

    2,1     4,3                     b -> c      move 1
                                    ------
    2       4,3     1               a -> b      move stack 2
            4,3,2   1               a -> c
            4,3,2,1                 b -> c
